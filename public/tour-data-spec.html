Itinerary writing rules (copyright-safe)

How we will generate day-by-day content after you approve Page 1 + Page 2.

1. Never copy competitor text Public itineraries = structure only (day order / places). All titles and paragraphs rewritten in our voice.
2. If online itinerary exists Use place sequence as reference → regenerate original day titles + descriptions + stay notes.
3. If no online itinerary Create a practical operator itinerary from destination logic (drive times, overnight bases, buffer days).
4. Every day must include dayNumber · short title · 2–5 sentence description (transfers, key visits, overnight place).
5. Already-on-site tours Keep existing itineraries unless you ask for a rewrite pass for consistency.
